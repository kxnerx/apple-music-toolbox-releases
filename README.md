# Music Toolbox releases

Downloads for **Music Toolbox**, a Mac app for your Apple Music library: AI-built playlists, vibe covers, and
now-playing controls in the menu bar.

**Install:** open the latest release below, download `MusicToolbox-<version>-arm64.dmg`, open it and drag Music
Toolbox into **Applications**. The first time, right-click the app and choose **Open** (it isn't notarized by
Apple). After that it updates itself: new versions download in the background and install when you restart.

You'll need an Apple Silicon Mac and, for the assistant and recommendations, your own
[OpenRouter key](https://openrouter.ai/settings/keys) (Music Toolbox → Settings). Your key and your library stay
on your Mac.

This repository only holds the built app; each release also carries the `releases.json` file installed copies
read to find updates.
